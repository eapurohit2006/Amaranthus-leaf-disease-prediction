# Amaranthus Frontend (React)

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will run on http://localhost:3000

## Build

```bash
npm run build
```

## Pages

- `/` - Home
- `/login` - Login page
- `/signup` - Signup page
- `/about` - About Us
- `/predict` - Disease prediction (requires login)
